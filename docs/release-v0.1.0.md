# v0.1.0

首次发布 Steam《王国保卫战：前线》金币倍率修改器。

- 支持连接运行中的原版游戏。
- 1–10 倍击杀金币和提前开波奖励。
- 支持恢复 1 倍、断开连接和异常退出后的自动复位。
- Windows x64 单文件 EXE，附 SHA256 校验文件。

下载 `KingdomRushFrontiersGoldTrainer.exe`，从 Steam 启动游戏并进入关卡后，打开修改器连接即可。兼容文件校验值见 `compatibility.json`。

已通过界面交互、缩放和模拟会话测试。实际关卡中的连接和奖励效果仍待实机验证。

First release for Kingdom Rush Frontiers on Steam. Connect to the running game and select 1×–10× gold from kills and early-wave calls. Windows x64; download the EXE and check it against SHA256SUMS.txt. Live level behavior still needs verification.
